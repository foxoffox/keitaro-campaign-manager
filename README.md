# Keitaro Campaign Manager

Обёртка над Keitaro Admin API на FastAPI, SQLAlchemy и Alembic. Форма создаёт кампанию с GEO-редиректом на Google и резервным потоком на выбранный оффер. В редакторе можно менять состав и доли офферов в локальном черновике. SQLite хранит управляемые кампании, привязки и черновики.

## Локальный запуск

Нужен Python 3.14. Выполняй команды из каталога проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

В `.env` укажи адрес трекера в `KEITARO_BASE_URL`, например `https://tracker.example`, и ключ Admin API в `KEITARO_API_KEY`. Приложение само добавляет `/admin_api/v1/`. По умолчанию SQLite создаётся в файле `keitaro.sqlite3` в каталоге проекта.

```powershell
python -m alembic upgrade head
python -m uvicorn app.main:app
```

- [Форма создания кампании](http://127.0.0.1:8000/)
- [Редактор офферов](http://127.0.0.1:8000/editor)
- [Swagger UI](http://127.0.0.1:8000/docs)
- [Проверка БД](http://127.0.0.1:8000/health)
- [Справочники доменов, групп кампаний, источников и офферов](http://127.0.0.1:8000/api/keitaro/catalogs)

Запуск рассчитан на локальную работу. Ключ хранится в окружении сервера. Без настроек трекера маршрут справочников возвращает HTTP 503.

## Создание кампании

Введи название и двухбуквенный GEO-код ISO 3166-1. Выбери домен, группу, источник и оффер из справочников трекера. Кампания сначала создаётся отключённой. Приложение настраивает оба потока, вызывает их включение в Keitaro, проверяет сохранённые параметры и записывает ID в SQLite. Затем включает саму кампанию.

API принимает `POST /api/campaigns` с `request_id` (UUID v4) и полями `name`, `country`, `domain_id`, `group_id`, `traffic_source_id`, `offer_id`. Повтор успешного запроса с теми же параметрами и UUID вернёт тот же результат. Если связь прервалась во время создания и результат нельзя подтвердить, повтор вернёт ID кампании, если он известен, и alias для сверки в Keitaro.

## Редактор офферов

Выбери кампанию, созданную через обёртку. Редактор загружает оба потока из Keitaro. Действия «Добавить в черновик», «Удалить», «Вернуть» и «Закрепить» сохраняются в SQLite и переживают перезагрузку страницы. «Отменить черновик» возвращает последнее загруженное состояние.

Закрепление фиксирует текущую долю. При изменении состава остаток до 100% делится поровну между активными офферами без закрепления. Если остаток не делится нацело, лишние процентные пункты получают офферы с меньшими ID. Удалённая строка остаётся в списке с 0%. Пустой поток или сумма, отличная от 100%, отмечаются в интерфейсе.

«Опубликовать в Keitaro» доступна при сумме активных долей 100%. Сервер перечитывает поток перед записью и сверяет его конфигурацию, состав и доли с исходным состоянием черновика. Обновляет только привязки офферов, затем перечитывает поток и подтверждает опубликованный результат. Закрепления и история удалённых привязок хранятся в SQLite.

При конфликте нажми «Обновить из Keitaro». Редактор сохранит черновик и покажет, что исходное состояние изменилось. Черновики, созданные до миграции `0004`, нужно отменить и создать заново, чтобы записать исходную конфигурацию. Если Keitaro не подтвердил запись, обновление сверит её результат повторно.

Для локального запуска используй один процесс Uvicorn. Он выполняет операции над черновиком одной кампании последовательно. Admin API не предоставляет условную запись, поэтому параллельное изменение напрямую в Keitaro между чтением и записью исключить нельзя.

## Миграции

```powershell
python -m alembic current
python -m alembic check
python -m unittest discover -s tests
```

Текущая ревизия — `0004`. `python -m alembic upgrade head` работает и на пустой БД, и на БД с предыдущей ревизией. Проверку отката выполняй на отдельной БД. Команда `python -m alembic downgrade base` удаляет таблицы приложения и их данные.
